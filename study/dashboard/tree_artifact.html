개요

노드 상세 + R 학습 Node Detail + R Learning

좌측 트리에서 원형 노드(⭐ 최소 분기 노드)를 클릭하면 그 단계의 데이터 상태, R 검사 코드, YES/NO 변환 코드, 샘플 데이터 before/after, 핵심 PMX 개념이 함께 표시됩니다. 사각형 노드(leaf)는 변환 단계들의 R 함수 라이브러리를 펼쳐볼 수 있습니다.

경로 추적기 Trace Simulator

데이터 시나리오가 의사결정 트리를 통과해 어떤 최종 결과(자동 처리 / 수리 / 격리)에 도달하는지, 각 노드에서 어떤 판단이 일어나는지 단계별로 확인합니다.

직접 입력 모드는 트리 구조를 탐색하기 위한 학습용입니다. action_sequence에 의존하는 노드(N13/N14/N17/N19/N29)는 입력만으로 판정할 수 없어 근사치로 평가됩니다.
